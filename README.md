# ICB 2026 — Official Rules (Indoor Cricket Blast)

Animated, interactive rules presentation for **Indoor Cricket Blast 2026**, 26–27 December 2026, Harburg, Hamburg.

**Live:** https://platocode13.github.io/icb-2026-rules/

- Bangla, with English cricket terms
- Tap any **Rule x.x** chip to read the exact rulebook text (and organiser clarifications for 5.7, 6.4, 8.7)
- Animated scenes: bowling box footprints, bowling action release zone, bounce height, wicketkeeper box, fielder touch = 4
- Registration rush timeline for all 12 teams
- Q&A at the end

## Presenting
Arrow keys / Space / swipe to move. `F` or the corner button for full screen. On some slides the first press reveals the answer.

Works on phone and desktop. Single static page: `index.html` plus images.
